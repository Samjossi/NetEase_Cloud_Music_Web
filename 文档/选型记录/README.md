## 阅读须知

1. **时间敏感性**：选型记录反映的是特定时间点的技术判断，随着项目演进，某些决策可能已被更新或推翻。
2. **上下文依赖**：许多选型文档需要结合当时的代码版本、性能测试结果和业务需求来理解。
3. **决策依据**：每个选型文档都应包含明确的决策依据、对比分析和最终结论。
4. **实施记录**：部分选型文档包含实施记录，用于追溯具体修改的时间和文件。

## 何时查阅本文档

- **理解设计决策**：想知道为什么选择某种算法或方案时
- **方案对比参考**：遇到类似问题时，查阅历史选型分析作为参考
- **技术债务追溯**：了解某些技术选择的背景和权衡
- **新成员培训**：帮助新团队成员理解系统的设计演进过程
