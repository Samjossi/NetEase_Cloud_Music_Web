# 项目临时目录规范

## 目录结构

```
project-root/
├── .gitignore          # 已添加 .tmp/ 规则
├── .tmp/
│   └── README.md       # 目录用途说明
└── ...
```

## 1. 创建临时目录

- **位置**：项目根目录
- **路径**：`./.tmp/`
- **用途**：存放临时文件、自动化截图、缓存数据

## 2. 配置 `.gitignore`

在 `.gitignore` 文件中追加：

```gitignore
# 临时文件目录
.tmp/
```

## 3. 目录内说明文件

**文件路径**：`.tmp/README.md`

**内容**：

```markdown
# .tmp 目录

本目录用于存放项目运行过程中生成的临时文件，包括但不限于：

- 自动化测试截图
- 运行时缓存数据
- 临时日志文件
- 其他非持久化产物

**注意**：本目录已被加入 `.gitignore`，不会进入版本控制。
```
