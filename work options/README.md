# work options

本目录用于存放项目的 **Options / 方案选型文档**。

选型文档用于在技术或设计决策前，系统性地列出多个候选方案并对比其优劣，最终给出推荐结论。典型结构包括：
- 背景与约束
- 候选方案
- 各方案优缺点
- 综合对比表
- 推荐结论与后续实施要点

文件命名遵循 `文档编写规范.md`：
- 根目录文件：`YYYY-MM-DD-HH_方案标题.md`
- 中文优先，英文名后置
