> **状态**：草稿

## 1. 背景与目标

依据 `协议/自定义标题栏跨项目复用指南.md` 将自绘标题栏方案迁移到本项目。目标效果：

- 隐藏系统原生标题栏，左侧显示应用 Logo + 固定标题「网易云音乐」；
- 右侧最小化（—）/ 最大化（□⇄❐）/ 关闭（×）三按钮；
- 标题栏左键拖拽移动、双击切换最大化、最大化态拖拽自动还原并跟随光标；
- 窗口四边四角可拖拽缩放（八向热区）；
- 配色与应用风格协调（本项目无主题体系，按指南 §3.5 先固定一组配色，不硬编码进部件逻辑之外的散点）。

---

## 2. 项目现状与差异分析

与指南参考实现的差异，决定适配点：

| 项目 | 指南参考实现 | 本项目现状 | 适配决策 |
|:---|:---|:---|:---|
| 菜单栏 | `QMainWindow` 有 `QMenuBar`，需显式入容器 | 无菜单栏 | 中央容器只放 `[TitleBar][QWebEngineView]` |
| 主题体系 | 多主题 + `title_bar` 四键令牌包 | 无主题体系 | 固定一组配色常量，预留 `apply_theme` 接口不接线 |
| Logo | SVG 优先，PNG 兜底 | 仅 `icon/` 下 PNG | 使用 `icon/icon_32x32.png` |
| 关闭行为 | 直连 `window().close()` | `closeEvent` 已实现托盘最小化/确认弹窗逻辑 | 关闭按钮仍直连 `self.close()`，天然走既有 `closeEvent` 链路，零改动复用 |
| 内容控件 | 编辑器/终端等复合控件 | 单一 `QWebEngineView` | WebView 自有光标会覆盖缩放光标，必须按指南对叶子控件 `setCursor`/`unsetCursor` |

核心技术决策沿用指南：**移动/缩放优先交给 WM**（`startSystemMove()` / `startSystemResize(edges)`），API 返回 `False` 时才降级手动兜底。

## 3. 实施步骤

### 3.1 新增 `gui/title_bar.py`

照指南 §3.3 实现自包含 `TitleBar` 部件（约 200 行），要点：

```python
# gui/title_bar.py
# TitleBar.__init__ 关键设置
self.setFixedHeight(32)
self.setAttribute(Qt.WidgetAttribute.WA_StyledBackground, True)  # QSS 背景生效前提
```

- 三按钮 `QToolButton` 定宽 46、`NoFocus`；最小化/关闭直连 `window().showMinimized` / `window().close`，最大化走统一入口 `toggle_maximize()`；
- 给 `window()` 装 `eventFilter` 监听 `WindowStateChange`，同步 □⇄❐ 图标；
- `mousePressEvent` 优先 `windowHandle().startSystemMove()`，失败则记录 `_drag_offset` 手动兜底；
- 最大化态拖拽：按光标横向比例 `showNormal()` 后平移窗口接续拖拽；
- `mouseDoubleClickEvent` 左键 → `toggle_maximize()`；
- 配色以模块级常量（bg/text/hover/close_hover）定义，提供 `apply_theme` 形参占位，本项目暂不外接。

### 3.2 新增 `gui/window_resize.py`

照指南 §3.4 实现 `EdgeResizeController(window)`（约 180 行，一行安装）：

- QApplication 级事件过滤器，构造时给主窗口开 `WA_MouseTracking`；
- 窗口内缩 6px 热区，四边标志位按位或组合出四角；
- `MouseButtonPress` 命中热区：最大化/全屏态直接放行（热区禁用），否则优先 `startSystemResize(edges)`，兜底手动 `setGeometry` 并钳制 `minimumSize`；
- hover 时对事件命中的叶子控件 `setCursor`（关键：`QWebEngineView` 自有 I-beam/箭头光标必须被覆盖），离开热区 `unsetCursor`。

### 3.3 改造 `gui/main_window.py`

最小侵入三处：

```python
# gui/main_window.py
# 1) NetEaseMusicWindow.__init__ 开头，init_ui 之前
self.setWindowFlags(self.windowFlags() | Qt.WindowType.FramelessWindowHint)
# setMinimumSize(800, 600) 已存在，满足防缩塌要求

# 2) init_ui 中替换 setCentralWidget(self.web_view)
central = QWidget()
outer = QVBoxLayout(central)
outer.setContentsMargins(0, 0, 0, 0)
outer.setSpacing(0)
self.title_bar = TitleBar(self)
outer.addWidget(self.title_bar)
outer.addWidget(self.web_view)
self.setCentralWidget(central)

# 3) init_ui 末尾
self._resize_controller = EdgeResizeController(self)
```

适配点确认：

- Logo 路径按现有打包兼容写法（`sys._MEIPASS` 检测）取 `icon/icon_32x32.png`；
- 标题固定为「网易云音乐」，不跟随 `on_title_changed` 的网页标题（`setWindowTitle` 逻辑保留，供任务栏/Alt-Tab 使用）；
- 关闭按钮走 `self.close()` → 既有 `closeEvent`，托盘最小化与确认弹窗行为不变；
- 窗口几何保存（`saveGeometry`/`restoreGeometry`）不受无边框化影响，无需改动。

## 5. 风险与注意点

| 风险 | 说明 | 对策 |
|:---|:---|:---|
| WebView 光标覆盖 | `QWebEngineView` 内部 Chromium 光标优先级高 | 严格按指南对叶子控件 `setCursor`/`unsetCursor`，重点验收 |
| WebEngine 与无边框窗口兼容性 | 个别驱动下帧缓冲偶发渲染异常 | 启动后目视检查 WebView 区域无黑块/残影 |
| 打包路径 | PyInstaller 下 Logo 路径失效 | 沿用 `sys._MEIPASS` 兼容写法，打包后回归验证 |
| 内联 QSS 背景不生效 | `WA_StyledBackground` 漏开 | 指南已列为坑点，实现后首查 |
