# 通用软件高保真复刻 Prompt — 协议





## 一、交付与架构约束
- **禁止假实现交付**：最终产物必须是可运行的真实软件，不是原型图、不是演示 DEMO、不是截图拼接。
- **技术栈不锁定**：根据目标平台选择合适技术栈，但选型理由必须在文档中说明。
- **模块化架构**：核心功能（编辑器、终端、文件系统、插件、AI）必须解耦，禁止大泥球代码。

## 二、交互真实性红线（绝对禁止项）
- **禁止假 UI**：所有可见控件必须对应真实功能模块，禁止占位符面板、装饰性按钮、静态文本伪装状态。
- **禁止死链**：任何可点击元素（菜单、按钮、图标、链接）必须有确定响应。未实现功能必须弹出明确提示（如 "未实现：XXX"），禁止静默无响应。
- **禁止只读编辑器**：任何文本/代码编辑区域必须真实可编辑，支持撤销（Ctrl+Z）、重做、选区、复制粘贴，禁止用静态高亮伪装编辑器。
- **禁止终端错位**：终端模拟器必须真实解析命令、维护环境状态（当前目录、变量）、支持历史记录（↑↓）、清屏、路径补全，禁止打字机动画或静态日志伪装。
- **禁止假多标签**：多文档/多窗口系统必须真实管理状态，切换后保留滚动位置、编辑状态、未保存标记，关闭未保存文件必须提示。
- **禁止假菜单**：菜单栏/上下文菜单的每一项必须真实响应，禁止仅展开无动作。
- **禁止假插件**：扩展/插件系统中展示的所有插件必须有真实功能，禁止仅展示图标和描述。

## 三、核心组件深度要求（按功能域抽象）
### 3.1 编辑器域
- 真实可编辑，支持 ≥20 种语言的语法高亮
- 多主题切换（≥5 套，含深色/浅色/高对比）
- 查找替换、多光标、自动缩进、括号匹配、代码折叠

### 3.2 视图系统
- 左侧 Activity/侧边栏：≥5 个可切换视图，每个有真实功能面板
- 底部面板：≥4 个可切换面板（终端、输出、问题、调试等），全部可交互
- 状态栏：实时反映状态，点击可触发对应操作

### 3.3 终端/命令系统
- 内置 ≥12 条真实可用命令（文件操作、系统信息、帮助等）
- 支持 REPL 模式（与内置脚本引擎或 AI 助手交互）
- 命令历史、Tab 补全、环境变量继承

### 3.4 插件/扩展系统
- 至少 5 个扩展具备真实功能（如格式化、Lint、版本控制可视化、实时预览、HTTP 客户端）
- 支持启用/禁用/配置，插件状态持久化

### 3.5 AI 助手（如适用）
- 真实可对话，支持多轮上下文，可执行命令或修改当前文档

## 四、状态与持久化
- **会话不丢失**：软件重启/刷新后，打开的文件、编辑器内容、布局状态、配置、终端历史必须完整恢复。
- **未保存保护**：未保存文件必须有视觉标记（如点号、颜色变化），关闭前提示保存。
- **配置持久化**：用户设置、主题选择、快捷键绑定必须落盘。

## 五、视觉与体验
- **像素级对标**：完全复刻目标软件的视觉系统（配色、间距、字体、图标、阴影层级、动画曲线）。
- **拖拽与调整**：面板可拖拽调整尺寸、Tab 可拖拽排序、文件树可拖拽移动。
- **响应式/自适应**：适配不同分辨率/DPI，布局不崩坏。

## 六、输入系统
- 快捷键体系：≥30 个真实可用快捷键，覆盖文件、编辑、搜索、视图、终端、命令面板。
- 命令面板：支持模糊搜索所有可用命令。
- 快捷键冲突检测。

## 七、验收标准
- **可交互率 ≥80%**：所有 UI 元素中，具备真实功能的占比不低于 80%。
- **零 Critical 错误**：运行时无崩溃、无未捕获异常。
- **稳定性测试**：连续高强度操作 30 分钟不崩溃、不内存泄漏。
- **性能基线**：冷启动 ≤3 秒，编辑器输入延迟 ≤16ms，大文件（≥1MB）不卡顿。
