# GUI 设计风格规范 · 跨软件复刻指南

> **状态**：已确认
> **范围**：全界面视觉风格 —— 设计语言、色彩、圆角、间距、控件视觉、交互状态（不含字体与字号）
> **时间**：2026-07-28 13:11 (UTC+8)
> **用途**：将本界面风格复刻到其他软件/框架时，以此文档作为唯一的视觉基准。本文档**不涉及任何框架或代码结构**，仅描述「长什么样」；任何平台（Web / Electron / Flutter / SwiftUI / WinUI / Qt 等）均可参照实现。

---

## 1. 设计基因

**一句话基调**

> 苹果风 + 1px 描边体系：描边层次优于色块分区；焦点只变色不出框；卡片化圆角层级递减；滚动条隐形；菜单栏 / 状态栏融入窗口底色；反色浮层提示。

### 核心设计铁律（7 条，不可妥协）

| # | 原则 | 说明 |
|:--|:---|:---|
| 1 | 描边分层，禁色块分区 | 面板/卡片用 1px 浅灰描边 + 微偏底色区分，**不用深色块 / drop-shadow / 浮雕**分割区域 |
| 2 | 焦点只变色，不出框 | 输入框 focus 时描边转为强调色，**不改变宽度、不添加外发光、不跳动** |
| 3 | 圆角三级递减 | 容器 8px → 内容物 6px → 项 3~4px，**不可颠倒或自创**（详见 §5） |
| 4 | 滚动条隐形 | 10px 宽无箭头、半透明圆角滑块、通路透明，**hover 才略微加深** |
| 5 | 菜单栏 / 状态栏融入窗口底 | 底色透明（和窗口共享同一底色），**不做独立色条** |
| 6 | 浮层反色 / 透明化 | 弹出框四角真透明（严禁矩形底座残留），深灰底白字工具提示 |
| 7 | 强调色单源辐射 | 一个主题强调色（accent），通过不同透明度的 rgba 叠色覆盖 hover / pressed / 选中 / 浮层描边等全部交互态 |

## 2. 色彩系统

本风格提供 4 套亮色主题（无深色）。以下以**默认主题「云白」**为基准详细说明，其余三主题仅列差异色值。

### 2.1 设计语义色板

色彩按**语义角色**组织，不按"调色板"思维——工程师请勿在代码中写死 `#0765d4`，而应理解为"这是这里用的是 `accent`"。

| 语义令牌 | 角色 | 在界面中的位置 |
|:---|:---|:---|
| `窗口底色` | 最底层画布 | 主窗口 / 对话框背景 |
| `侧栏底色` | 微偏，区隔但不割裂 | 左侧栏 / 右侧栏（比窗口底稍偏，三栏似分未分） |
| `卡片底色` | 浮于背景的内容容器 | 面板卡片、树 / 列表容器 |
| `强调色` | 交互标识 | 选中块底、焦点描边、激活下划线、选中菜单项 |
| `正文色` | 主文字 | 标题、正文、激活 tab |
| `次级文字色` | 弱化文字 | 提示说明、未激活 tab、徽标 |
| `描边色` | 结构分割 | 卡片边框、输入框边框、按钮边框、分隔线 |
| `描边加深色` | hover 强化 | 输入框 / 按钮 / 下拉框 hover 时的描边 |
| `输入底色` | 输入控件实体 | 输入框底色、按钮底色 |
| `浮层底色` | 弹出浮层 | 菜单、下拉列表、弹出框背景 |
| `浮层描边` | 浮层层级护框 | 下拉列表边框、菜单边框（半透明，保浮层层级感） |
| `浮层分隔线` | 菜单内分隔 | 菜单分隔线（极淡半透明） |
| `列表悬停微染` | 列表项 hover | 树 / 列表项悬停时极淡的背景染色 |
| `按钮悬停微染` | 按钮 hover | 按钮悬停时极淡的背景染色 |
| `按钮按压染` | 按钮 pressed | 按钮按下时稍深的背景染色 |
| `按钮禁用三件套` | 按钮 disabled | 禁用态：文字淡化、背景微灰、描边极淡 |
| `工具提示背景 / 文字` | 反色提示 | 深灰底白字的 tooltip |

### 2.7 透明叠色规则（复刻关键）

本风格的核心手法之一：**交互反馈色的生成公式不是独立选色，而是"强调色 + 不透明度"**。例如云白主题中：

| 反馈层 | 公式 | 结果 |
|:---|:---|:---|
| 列表项 hover | `accent × 7%` | `rgba(7, 101, 212, 0.07)` |
| 按钮 hover | `accent × 7%` | 同上 |
| 按钮 pressed | `accent × 12%` | `rgba(7, 101, 212, 0.12)` |
| 菜单描边 | `accent × 25%` 或 `black × 15%` | 按主题 |
| 浮层分隔线 | `accent × 15%` 或 `black × 10%` | 按主题 |

换一个主题时，只需更改 `accent` 底色的色相，其余比例和逻辑不变。这是保持"跨主题统一感"的精髓。

## 3. 字体与字号

**本指南不规定字体与字号。**

字体族、字重、字号均属于各实现项目的自主选择范围，**不构成复刻验收项**。实现方可根据目标平台的系统字体惯例、用户偏好设置或产品定位自行决定。

唯一与本风格相关的要求是：文字层级通过**色彩**区分（正文色 / 次级文字色，见 §2.1），而不是依赖字号或字重的强烈对比。

## 4. 圆角层级体系

全局统一，不可自创。三级递减：

| 层级 | 圆角 | 应用对象 |
|:---|:---:|:---|
| **容器层** | **8px** | 面板卡片、浮层（菜单 / 下拉弹出） |
| **内容层** | **6px** | 输入框、按钮、下拉框、树 / 列表容器、工具提示 |
| **项层** | **3~4px** | 列表选中块、菜单项、菜单栏项 |

设计逻辑：外层大、内层小，视觉层级由外向内收敛。

## 5. 间距与布局体系

### 5.1 窗口级外边距

主窗口内容区距边缘：**上 12px · 右 6px · 下 0 · 左 12px**。布局 spacing 为 0（由各面板自行管理内边距）。

### 5.2 面板级内边距

| 对象 | padding |
|:---|:---|
| 面板标题行 | `2px 8px` |
| 面板提示 / 弱化文字 | `2px 8px` |
| 面板间间距 | `6px` |
| 菜单栏文字距窗口上缘 | `24px`（含内部 `21px + 4px` 的分配） |
| 菜单栏底 → 卡片顶 | `12px` |

### 5.3 分隔与分栏

| 对象 | 规格 |
|:---|:---|
| 分隔线 | 1px 宽 / 高，色值见 §2 |
| 分栏把手（拖拽条） | 4px 宽 / 高，常态透明，hover 显现微染色 |

## 6. 控件视觉规范（逐项）

以下全部以**默认主题「云白」**为基准。

### 6.1 输入框

| 属性 | 常态 | hover | focus |
|:---|:---|:---|:---|
| 背景 | `#ffffff` | 不变 | 不变 |
| 描边 | 1px `#d2d2d7` | 不变 | 1px `#0765d4` |
| 圆角 | 6px | — | — |
| 内边距 | `3px 7px` | — | — |
| 宽度变化 | — | ❌ 禁止 | ❌ 禁止跳动 |

**关键**：focus 只把描边从灰色换成强调蓝色，**不改变宽度、不添加外发光**（很多框架默认加 glow，必须关闭）。

### 6.2 按钮

| 属性 | 常态 | hover | pressed | disabled |
|:---|:---|:---|:---|:---|
| 背景 | `#ffffff` | `rgba(7, 101, 212, 0.07)` | `rgba(7, 101, 212, 0.12)` | `#f9f9fa` |
| 描边 | 1px `#d2d2d7` | 1px `#c0c0c5` | 不变 | 1px `#e8e8ea` |
| 文字色 | `#1d1d1f` | 不变 | 不变 | `rgba(29, 29, 31, 0.35)` |
| 圆角 | 6px | — | — | — |
| 内边距 | `3px 11px` | — | — | — |

**工具按钮**（小型按钮，如"新建 +"、"折叠 ▸"）同样采用实体化范式：实底 + 描边 + 6px 圆角，仅内边距收窄至 `2px 8px`。

### 6.3 下拉框

| 属性 | 常态 | hover |
|:---|:---|:---|
| 背景 | **透明**（随所在面板底色） | 透明 |
| 描边 | 1px `#d2d2d7` | `#c0c0c5` |
| 圆角 | 6px | — |
| 内边距 | `2px 7px` | — |
| 箭头区 | 宽 20px，无描边 | — |

> ⚠️ **严禁**给下拉框本体设背景色。若设了背景色，某些平台 / 框架的弹出列表选中行会变白底白字（不可见）。

弹出列表：

| 属性 | 值 |
|:---|:---|
| 背景 | `#f5f5f7` |
| 文字 | `#1d1d1f`（不继承窗口，独立写） |
| 圆角 | 8px |
| 描边 | 1px `rgba(0, 0, 0, 0.15)` |
| 内边距 | `4px` |
| 选中项 | 底 `#0765d4` 配白字 |

### 6.4 树视图 / 列表视图（卡片化）

| 属性 | 值 |
|:---|:---|
| 容器背景 | `#ffffff` |
| 容器描边 | 1px `#d2d2d7` |
| 容器圆角 | 6px |
| 容器内留白 | 2px（选中块不贴边） |
| 焦点虚线 | **无**（`outline: none`） |

单项：

| 状态 | 背景 | 文字色 | 圆角 |
|:---|:---|:---|:---|
| 常态 | 透明 | `#1d1d1f` | — |
| hover | `rgba(7, 101, 212, 0.07)` | 不变 | 3px |
| 选中 | `#0765d4` | `#ffffff` | 3px |

单项内边距：`4px 6px`，最小高度 20px。

### 6.5 标签页（TabBar）

细条范式：标签透明底融入所在栏。

| 属性 | 未选中 | hover | 选中 |
|:---|:---|:---|:---|
| 背景 | 透明 | 透明 | 透明 |
| 文字色 | `#86868b` | `#1d1d1f` | `#1d1d1f` |
| 底下一划线 | 2px 透明 | — | 2px `#0765d4` |
| 内边距 | `2px 8px`（终端）或 `3px 10px`（聊天） | — | — |

Pane（内容区）去框 / 透明，不额外包裹。

关闭按钮：仅定义 hover 态（背景微染 `rgba(7, 101, 212, 0.07)` + 3px 圆角），**禁止定义常态**（会导致平台原生 ✕ 图标消失）。

### 6.6 单行 / 多行文本区

- 普通文本编辑区（QLineEdit 风格）：同 §6.1 输入框
- **代码查看区**：透明背景 + 无自身描边。代码查看器嵌在面板卡片内，由卡片统一画框，自身保持"文档感"。

## 7. 浮层与弹出通用规则

### 7.1 透明化（消除矩形底座）

任何弹出浮层（菜单 / 下拉列表 / 右键菜单 / 自定义弹出）必须满足：

- **四角真透明**：圆角外区域不可有矩形底色残留。
- **描边保层级**：浮层是弹出的、叠在其他内容上——需 1px 半透明描边来标识"浮层边界"。内部面板靠 1px 实色描边区分，浮层靠半透明描边，二者不能混用。
- **文字色独立**：浮层内的文字色必须显式指定，**不可依赖继承**（平台默认继承行为不一致）。

### 7.2 右键标准菜单

文本编辑区的右键菜单：
- 使用平台 / 框架内置的标准上下文菜单（复制、粘贴、剪切、全选等），不要自建菜单项
- 如需套用浮层透明化规则，在处理菜单对象时统一注入

## 10. 视觉要点速记（给工程师）

以下是一个"感觉清单"，让工程师看完就能抓准风格的核心气质：

1. **白色为主，灰色分层**：不用任何强色块。区域区分靠极淡底色偏移 + 1px 描边，不是靠 drop-shadow 或不同背景色。
2. **强调色收敛**：整个界面只有一种强调色（蓝 / 绿 / 棕等），所有 hover / 选中 / 焦点 / 下划线都从这同一色衍生。
3. **圆角内敛**：最大 8px、中 6px、小 3~4px，不会有 16px 以上的"泡泡感"。
4. **描边克己**：1px 灰线是结构语言，不是装饰。hover 时描边微微加深（~7%），安静但不迟钝。
5. **滚动条隐身**：不滚动时不吸引注意。轨道透明，滑块低不透明度灰块。
6. **浮层轻盈**：半透明描边 + 四角真透明 + 浅灰背景——浮层像"浮在纸上的一张半透明纸"，不是硬切出来的方框。
7. **文字克制**：正文不纯黑（`#1d1d1f`），次级灰不抢戏（`#86868b`）。黑白色阶控制在 5 档以内。
8. **间距紧凑但不拥挤**：小 padding + 收紧的行间留白，适合工具型界面（非消费型内容）。
9. **反馈安静**：hover 染色极淡（7~8%），pressed 稍深（12~13%），选中才实色。没有剧烈色彩跳动。
10. **菜单栏 / 状态栏不是"栏"**：它们透明融入窗口底色——从视觉上它们不是独立界面分区，而是"窗口顶 / 底部的文字和控件"。

## 11. 复刻验收清单

| # | 检查项 | 视觉标准 |
|:--|:---|:---|
| 1 | 描边分层 | 描边看到的层次感优于色块分区；无明显 drop-shadow 或深色块切割 |
| 2 | 焦点跳出 | 输入框 focus 时描边换色，控件不抖动、不加外发光 |
| 3 | 圆角层级 | 容器 8px / 内容 6px / 项 3~4px，无颠倒 |
| 4 | 滚动条 | 10px 宽，轨道透明，无箭头，滑块半透明圆角 |
| 5 | 菜单栏通透 | 菜单栏 / 状态栏透明融入窗口底，不是独立色条 |
| 6 | 工具提示反色 | 深灰底 `#323236` + 浅灰白字 `#f5f5f7`，无边框 |
| 7 | 按钮实体化 | 白底 + 1px 描边 + 6px 圆角；hover 极淡强调色染 |
| 8 | 列表卡片化 | 白底 + 1px 描边 + 6px 圆角 + 2px 内留白；选中块不贴边 |
| 9 | 浮层四角透明 | 菜单 / 下拉四角真透明，无矩形底色残留 |
| 10 | 零硬编码 | 所有颜色统一走语义令牌，不存在 `color: #0765d4` 的分散硬编码 |
| 11 | hover 微染量 | 列表 / 按钮 hover 在 7~8% 不透明度，不是明显的色块 |
| 12 | 文字层级 | 正文 `#1d1d1f` / 次级 `#86868b`，不超过 5 档灰阶 |
| 13 | 多主题一致 | 换主题只换强调色相 + 底色微调，交互比例不变 |
