# 自定义标题栏跨项目复用指南

> **状态**：已确认
> **范围**：PySide6 / Qt6 桌面应用的自绘标题栏（无边框窗口）方案
> **时间**：2026-08-11 08:06（UTC+8，编写）/ 2026-07-30（方案落地）

---

## 1. 目标与效果

隐藏系统原生标题栏，改由应用自绘：

- 左侧：Logo（SVG 优先，PNG 兜底）+ 固定标题文字；
- 右侧：最小化（—）/ 最大化（□⇄❐）/ 关闭（×）三按钮；
- 交互：左键拖拽移动窗口、双击切换最大化、最大化态拖拽自动还原并按光标横向比例跟随；
- 窗口四边四角可拖拽缩放（无边框化后原生热区消失，需自绘补齐）；
- 配色随应用主题联动切换，不硬编码。

参考实现：`gui/title_bar.py`、`gui/window_resize.py`、`gui/main_window.py`、`gui/theme.py`。

---

## 2. 总体架构

四块拼图，缺一不可：

| 拼图 | 作用 | 关键 API |
|:---|:---|:---|
| 无边框化 | 去掉系统原生标题栏与边框 | `Qt.WindowType.FramelessWindowHint` |
| `TitleBar` 部件 | 自绘标题栏（Logo/标题/三按钮/拖拽/双击） | `QWindow.startSystemMove()` |
| `EdgeResizeController` | 八向边缘缩放热区 | `QWindow.startSystemResize(edges)` |
| 主题令牌包 | 每主题一组 `title_bar` 配色（bg/text/hover/close_hover） | 内联 QSS |

**核心技术决策：优先把移动/缩放交给 WM（窗口管理器）。**
`startSystemMove()` / `startSystemResize(edges)` 是 Qt6 原生 API，Wayland（xdg-toplevel）与 X11 下均由 WM 接管，流畅无闪烁；仅当 API 返回 `False`（WM 不支持）时降级为手动 `move` / `setGeometry` 兜底。这是本方案与网上常见的"纯手动拖拽"实现最大的区别——不要在能走系统路径时手写像素跟随。

## 3. 实施步骤

### 3.1 主窗口无边框化

```python
# gui/main_window.py（MainWindow.__init__ 开头）
# 保留 Window 类型标志，任务栏/Alt-Tab/最小化行为不变
self.setWindowFlags(self.windowFlags() | Qt.WindowType.FramelessWindowHint)
self.setMinimumSize(900, 500)  # 防手动缩放兜底时缩坏布局
```

### 3.2 装配 TitleBar 与菜单栏

`QMainWindow` 没有 API 在菜单槽**之上**插入部件，因此标题栏行与菜单栏都要显式放进中央容器：

```python
# gui/main_window.py（MainWindow._build_layout）
# 中央容器外层 vbox 零边距零间距，自上而下 [TitleBar][QMenuBar][内容]
self.title_bar = TitleBar(self)
outer.addWidget(self.title_bar)
self._menu_bar = QMenuBar(self)  # 显式创建，reparent 进容器，不再占用菜单槽
outer.addWidget(self._menu_bar)
```

再一行安装边缘缩放控制器：

```python
# gui/main_window.py（MainWindow.__init__，minimumSize 设定之后）
self._resize_controller = EdgeResizeController(self)
```

### 3.3 TitleBar 部件

完整实现直接照抄 `gui/title_bar.py`（约 200 行，自包含）。要点：

```python
# gui/title_bar.py（TitleBar.__init__）
self.setFixedHeight(32)   # 定高 32px
# qss background 对 QWidget 需显式开启样式绘制（不设则背景色不生效，易踩坑）
self.setAttribute(Qt.WidgetAttribute.WA_StyledBackground, True)
```

- **三按钮**：`QToolButton`，定宽 46，`NoFocus`；最小化/关闭直连 `window().showMinimized` / `window().close`，最大化走统一入口 `toggle_maximize()`（按钮与双击共用）。
- **最大化按钮图标同步**：给 `window()` 装 `eventFilter`，监听 `WindowStateChange`——任务栏还原、WM 快捷键最大化等外部途径触发的窗口态变化也能同步 □⇄❐。
- **拖拽移动**（`mousePressEvent`）：

```python
# gui/title_bar.py（TitleBar.mousePressEvent）
if window.isMaximized():
    self._restore_for_drag(event)  # 最大化态按下：先还原（见下）
handle = window.windowHandle()
if handle is not None and handle.startSystemMove():
    return  # WM 接管
# 兜底：WM 不支持时记录偏移，mouseMove 里手动 move 跟随
self._drag_offset = (
    event.globalPosition().toPoint() - window.frameGeometry().topLeft())
```

- **最大化态拖拽还原**：记录光标在栏内横向比例，`showNormal()` 后按比例平移窗口，使光标接续拖拽位置不变（与系统原生窗口行为一致）：

```python
# gui/title_bar.py（TitleBar._restore_for_drag）
ratio = event.position().x() / max(self.width(), 1)
window.showNormal()
new_x = event.globalPosition().x() - ratio * window.width()
new_y = event.globalPosition().y() - TITLE_BAR_HEIGHT // 2
window.move(int(new_x), int(new_y))
```

- **双击**：`mouseDoubleClickEvent` 左键 → `toggle_maximize()`。
- 标题栏内的 `QLabel` 默认忽略鼠标事件，事件自然上冒至标题栏，无需特殊处理；按钮自吞事件，不串扰。

### 3.4 八向边缘缩放

完整实现照抄 `gui/window_resize.py`（约 180 行，自包含，`EdgeResizeController(window)` 一行安装）。设计要点：

- **QApplication 级事件过滤器**：比递归给每个子控件装过滤器简单，动态增删子控件无需追踪；hover 移动事件沿父链上冒至开了 `WA_MouseTracking` 的主窗口（控制器构造时自动开启），过滤器即可收全事件。
- **热区判定**：窗口内缩 6px，`x < 6` 命中左边、`y < 6` 命中上边……四边标志位按位或组合，四角由组合自然得出。
- **缩放发起**（`MouseButtonPress` 命中热区时）：

```python
# gui/window_resize.py（EdgeResizeController._try_start_resize）
if window.isMaximized() or window.isFullScreen():
    return False  # 最大化/全屏态热区整体禁用（与原生窗口行为一致）
handle = window.windowHandle()
if handle is not None and handle.startSystemResize(edges):
    return True   # WM 接管；吞掉按下，防边缘文本选择/终端焦点串扰
# 兜底：记录起始几何与全局坐标，MouseMove 里手动 setGeometry，
# 各边界钳制 minimumSize（防三栏布局缩塌）
```

- **hover 光标**：进入热区对事件命中的**叶子控件** `setCursor`（覆盖编辑器 I-beam、终端光标等子控件自有光标），离开热区 `unsetCursor` 还原——这是"缩放光标不被子控件覆盖"的关键机制。边⇄角滑动时更新光标形状（↔↕↘↙）。

### 3.5 主题联动

原实现踩过的坑：标题栏最初硬编码深色 `#252526`，四个亮色主题下与窗口严重割裂。定案：**每主题一个 `title_bar` 令牌包，四键**：

```python
# gui/theme.py（TitleBarPack 与各主题调色板条目）
class TitleBarPack(TypedDict):
    bg: str          # 标题栏背景
    text: str        # 标题文字与按钮前景
    hover: str       # 按钮悬停背景（一般半透明黑/主题色）
    close_hover: str # 关闭按钮悬停（跨主题通用警示红 #c75450）
```

曾评估过复用现有 `sidebar_bg` 等令牌（A 方案），核算后与 `window_bg` 色差 <2%，亮色主题下标题栏与内容区无区分度，否决——**标题栏必须有自己的背景令牌**。

`TitleBar` 提供 `apply_theme(theme)`，按令牌包重建内联 QSS：

```python
# gui/title_bar.py（TitleBar.apply_theme）
self.setStyleSheet(build_qss(get_theme_palette(theme)["title_bar"]))
```

接线两处：构造时用持久化的启动主题初始化；主窗口 `switch_theme` 转发链里追加一行 `self.title_bar.apply_theme(theme)`——因为内联 QSS 不受 app 级 QSS 管辖，必须随链手动重刷。

## 4. 验收清单

交付给测试或自查时按此过一遍：

- [ ] 窗口无系统原生标题栏，任务栏/Alt-Tab 图标与标题正常（保留 `Window` 类型标志）；
- [ ] 拖拽标题栏空白处可移动窗口（Wayland 与 X11 各验证一次）；
- [ ] 双击标题栏切换最大化/还原；任务栏还原、WM 快捷键最大化后按钮图标正确同步 □⇄❐；
- [ ] 最大化态按住标题栏拖拽，窗口还原并跟随光标（横向比例不变）；
- [ ] 四边四角 hover 出缩放光标（不被编辑器/终端等子控件光标覆盖），可拉大拉小，且缩不小于 minimumSize；
- [ ] 最大化/全屏态边缘热区禁用；
- [ ] 切换全部主题，标题栏配色即时联动，关闭按钮悬停为警示红。

## 5. 常见坑速查

| 坑 | 现象 | 解法 |
|:---|:---|:---|
| `WA_StyledBackground` 未开 | QSS 背景色对 QWidget 不生效 | 显式 `setAttribute(..., True)` |
| `QMainWindow` 菜单槽 | 无法在菜单栏上方插标题栏 | 标题栏 + `QMenuBar` 显式放进中央容器布局 |
| 纯手动拖拽 | Wayland 下闪烁/掉帧 | 优先 `startSystemMove()`，手动仅兜底 |
| 子控件自有光标 | 边缘 hover 出 I-beam 而非缩放光标 | 对事件命中的叶子控件 setCursor/unsetCursor |
| 内联 QSS 不随主题切换 | 切主题后标题栏配色不变 | 主窗口 switch_theme 转发链手动重刷 |
| 最大化按钮图标失真 | 任务栏还原后仍显示 ❐ | eventFilter 监听 WindowStateChange |

## 6. 不实施项（已评估，供参考）

以下为当时评估后**否决**的增强项，复用时无需再做：

- **右键标题栏弹系统菜单**（`startSystemMenu` 类）：收益低，与自绘风格割裂；
- **ESC 取消拖拽/缩放**：WM 接管路径天然支持，手动兜底路径意义不大；
- **标题栏显示 Git 分支**：标题固定为软件名，工作区信息由专门面板承担；
- **热区向外扩**（窗口外也可抓边缩放）：需透明像素边距，侵入布局边距体系；
- **QSizeGrip / 第三方无边框库**：仅右下角单向、引入重依赖，均否决；
- **窗口阴影与贴边吸附**：阴影可用 QSS/平台能力另行叠加，贴边吸附由系统 WM 免费获得（拖到屏幕边缘自动半屏/全屏），无需自己实现。

## 7. 迁移最小改动量估算

新项目接入本方案：

1. 复制 `gui/title_bar.py`、`gui/window_resize.py` 两个文件（改 Logo 路径、标题文字、主题令牌查询函数三处适配点）；
2. 主窗口加三行：`FramelessWindowHint`、`TitleBar(self)` 入布局、`EdgeResizeController(self)`；
3. 主题体系加 `title_bar` 四键令牌包（无主题体系则可先硬编码一组色，后续再收编）；
4. `switch_theme` 转发链加一行 `title_bar.apply_theme(theme)`。

无第三方依赖，仅需 PySide6（Qt6）。
